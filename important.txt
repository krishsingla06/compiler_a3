# Variadic Function Support

✅ SUPPORTED:
- Declaring variadic functions: int foo(int x, ...);
- Calling variadic functions with extra arguments
- External library functions: printf, scanf, etc.

❌ NOT SUPPORTED:
- Implementing custom variadic functions
- va_list, va_start, va_arg, va_end macros
- Accessing ... arguments inside function body

RATIONALE:
The <stdarg.h> macros are architecture-dependent and would 
require implementing:
- Address-of operator (&)
- sizeof operator  
- Pointer arithmetic
- Preprocessor #define macros
- Platform-specific calling conventions

For this compiler, variadic functions are assumed to be 
provided by external libraries and linked at runtime.
